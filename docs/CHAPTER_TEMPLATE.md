## 本章任务

用一个方块世界问题引出语法，最后交付一个可以复查的查询结果。

## 1. 先看问题

说明服务器管理员为什么需要这个结果，并给出期望输出的列。

## 2. 先写最小查询

每段 SQL 只引入一个新概念，先跑通，再逐步加条件。

## 3. 解释结果

说明行数、空值、重复行和排序顺序。需要时给出 `EXPLAIN` 或边界情况。

## 4. 动手练

链接到 `exercises/` 中的独立题目。
