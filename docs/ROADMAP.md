# 学习路线图

## 学习目标

完成本路线后，你应该能够：

- 从多个业务问题中抽象出需要的表和字段；
- 用 `SELECT`、筛选、聚合、连接和窗口函数完成常见分析；
- 看懂一个查询为什么返回重复行或空结果；
- 使用 PostgreSQL 的日期、数组、`JSONB` 和 `EXPLAIN` 功能；
- 写出一份有结论、有证据、可以复查的周报 SQL。

## 关卡

| 关卡 | 章节 | 判断标准 |
|---|---|---|
| Lv.0 进入世界 | 安装文档 + 00 | 可以安装/启动 PostgreSQL，创建 schema，并用 `\dt` 找到表 |
| Lv.1 观察者 | 01～02 | 能独立查看、筛选、排序一张表 |
| Lv.2 记录员 | 03～04 | 能用聚合和连接回答“谁、在哪、多少” |
| Lv.3 探险队长 | 05 | 能把复杂问题拆成 CTE 的多步管线 |
| Lv.4 排行榜维护者 | 06～07 | 能用窗口函数和 PostgreSQL 特色语法 |
| Lv.5 服务器管理员 | 08～09 | 能考虑约束、索引和分析结果的可信度 |

## 每章自检清单

- [ ] 我能用一句话说出本章解决的业务问题。
- [ ] 我能不看答案重写核心查询。
- [ ] 我检查过结果的行数、空值和重复情况。
- [ ] 我完成了至少一个“变式挑战”。
- [ ] 我把查询保存成可复用的 `.sql` 文件。

## 后续可以怎么扩展

- 增加玩家背包快照，用 `JSONB` 记录物品数量；
- 使用 `COPY` 导入真实日志，练习批量加载；
- 给采集日志分区，比较分区前后的执行计划；
- 用 Python、Metabase 或 Superset 连接数据库，制作服务器看板；
- 加入怪物击杀、死亡和村民交易，完成更完整的运营分析。
